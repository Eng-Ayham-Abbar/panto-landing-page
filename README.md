# Panto Landing Page

مشروع تعليمي لتطبيق تصميم Panto للأثاث باستخدام HTML وCSS، بهدف تعلّم بناء واجهات الويب خطوة بخطوة، والتدرّب على استخدام Git وGitHub لتنظيم العمل ومراجعة التغييرات.

## مرجع التصميم

[Figma — Panto Furniture Landing Page](https://www.figma.com/design/cfpAHew7rce2sPHjvE0eS8/Panto---Furniture-Landing-Page-Design--Community-?node-id=1-28)

## التقنيات المستخدمة

- HTML5 لبناء هيكل الصفحة.
- CSS3 لتنسيق الصفحة.
- Git وGitHub لإدارة الإصدارات ومراجعة التغييرات.

## ملفات المشروع

- `index.html`: الملف الرئيسي للصفحة.
- `css/style.css`: ملف التنسيقات.
- `README.md`: وصف المشروع ومراحل العمل.

## التشغيل محلياً

1. انسخ المستودع:

   git clone https://github.com/Eng-Ayham-Abbar/panto-landing-page.git

2. انتقل إلى مجلد المشروع:

   cd panto-landing-page

3. افتح ملف `index.html` في المتصفح.

لا يحتاج المشروع حالياً إلى تثبيت مكتبات أو تشغيل خادم.

## أسلوب العمل

تُنفّذ كل مرحلة على برانش مستقل، ثم يُفتح Pull Request لمراجعة التغييرات قبل دمجها في `main`.

## نطاق المشروع

يركّز المشروع على الشكل والتخطيط والتجاوب باستخدام HTML وCSS فقط. وظائف البحث والسلة وتصفية المنتجات ليست ضمن المرحلة الحالية.
